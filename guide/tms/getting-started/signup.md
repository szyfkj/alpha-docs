# 注册与登录

账号分两种来源：**自己注册开一个新机构**，或者**被管理员邀请**加入已有机构。两种人
登录后看到的东西不一样，先确认你是哪一种。

## 自己注册一个新机构

注册即开通一个新机构，注册的人就是这个机构的**所有者**——拥有全部权限，后面由你来
邀请同事。

1. 打开注册页，填 **机构信息**：
   - **机构名称**（必填）——全平台唯一，重名会被拒绝。
   - **机构类型**、**机构规模**——选填，用于我们了解你的业务，不影响功能。
2. 往下填 **管理员信息**：**名**、**姓**、**电子邮件**、**电话号码**、**密码**、
   **确认密码**。
3. 点 **创建账户**。

密码有硬性要求，不满足会当场报错：

> 8–128 位，且至少各包含一个小写字母、一个大写字母、一个数字和一个特殊字符。

### 验证邮箱

创建成功后**还不能直接登录**。系统会发一封确认邮件，点邮件里的链接完成验证，页面会
提示确认成功并自动跳进系统。

链接失效或已被用过会提示确认失败——这种情况找管理员重发一封即可。

:::tip 没收到邮件
先翻垃圾邮件箱。企业邮箱常把这类系统邮件拦下来。
:::

### 注册时的常见报错

| 提示 | 意思 |
|---|---|
| 该邮箱已存在 | 这个邮箱注册过了，直接去登录 |
| 机构名称已存在 | 换一个机构名称 |
| 尝试次数过多 | 短时间内注册太频繁，等几分钟再试 |

### 注册没有完成

点 **创建账户** 后如果提示出错，这次注册不会留下半个账号，可以直接用同一个邮箱重新注册。

如果之前的某次注册只建好了登录账号、没建好机构，登录后会进入 **完成组织设置** 页面。页面上已经填好注册时填的机构名称、机构类型、机构规模和姓名，核对一下，补上 **电话号码**，点 **创建组织** 就进入系统，你就是这个机构的所有者。不想现在处理，点 **退出登录**。

提示"该邮箱已属于另一个账户，请联系客服"，说明这个邮箱已经被另一个账号使用，请联系我们处理。

## 被邀请加入已有机构

同事的账号不需要重新注册机构——由机构里有权限的人在 **设置 → 团队成员** 里建好账号，
系统发邀请邮件，收件人点链接设置自己的密码。

邀请链接里带着你的邮箱地址，**必须完整点开**。邮件客户端有时会把长链接折行，只复制
到一半就会看到"邀请无效 / 缺少邮箱地址"的提示。遇到这种情况：

- 回邮件里确认链接是完整的；
- 或者请管理员重新发一份邀请。

你的权限由建账号的人勾选，不是自己选的。登录后发现少菜单，见
[界面导航](./navigation)。

## 登录

用邮箱和密码登录。忘记密码点 **忘记密码？**，系统发重置邮件，按邮件里的链接设置
新密码。

司机不走这个入口——司机用的是手机上的扫码页，见[司机扫码](../driver/scan)。
