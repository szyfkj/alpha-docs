# 常见问题

## 界面

**看不到某个菜单。**
两道门：机构套餐和账号权限。先问同事看不看得到，见[功能与套餐](./features)。

**同事说的页面我怎么点不到。**
有几个页面确实不在菜单里，只能从相关页面进去：收款银行账户（从付款页）、
寄件人账户类型（从寄件人账户页）、自定义域名。见[界面导航](../getting-started/navigation)。

**点设置进去是"即将推出"。**
直接访问设置首页会看到占位页，真正的设置项都在 **设置** 下拉菜单里。

## 运单

**怎么手工建一票运单？**
后台没有单票录入表单。用[导入运单](../waybills/import)传一行，或走接口。

**导入后票数不对。**
CSV 里**一行是一个包裹**，不是一票运单。外部运单号相同的行会合成一票。
见[导入运单](../waybills/import)。

**打标签时有几票被跳过。**
状态为「运单已创建」的打不了，弹窗会列出是哪几票。见[打印标签](../waybills/labels)。

**"合并运单"这一项不出现。**
五个条件要同时满足：两票以上、同一寄件账户、同一服务、同一路线、都不是合并主运单。
见[合并运单](../waybills/consolidate)。

**"合并运单"是灰的。**
这一项下面写着是哪个条件不满足：服务、寄件人账号或路线不一致，或者有运单没有服务。合并主运单可以再合并。见[合并运单](../waybills/consolidate)。

**指定承运商时提示状态不可分配。**
部分运单当前状态不允许转交，弹窗会列出来。取消勾选或先把状态推到位。

## 配送

**规划页什么都不显示。**
站点、服务区域、车队**三个都选了**才会加载。见[配送规划](../delivery/planning)。

**派司机时下拉是空的。**
只列出车辆类型与这趟配送匹配的司机。回[司机](../partners/drivers)页确认车辆类型。

**排不了路线。**
两种原因：所选站点没有坐标，或者这趟配送里还没有运单。

**轨迹地图是空的。**
这趟里的运单没有可用坐标，去[地址预处理](../delivery/address)处理。

## 司机

**司机扫码时事件类型下拉只有一项。**
正常——下拉按权限过滤。要更多类型，在 **设置 → 团队成员** 里给对应的扫码子权限。

**摄像头打不开。**
换 Chrome 或 Edge，并允许摄像头权限。实在不行用**手动输入运单号**。

**司机发了照片，LINE 没反应。**
这位司机还没注册。见[送达确认](../driver/pod)。

**确认链接过期了。**
确认链接 7 天有效，重新发一遍包裹照片会生成新的。邀请注册链接约 2 天有效。

## 账单

**勾了账单开不了发票。**
一张发票只能开给一个对象。按客户或寄件人先筛再勾。见[账单](../billing/billings)。

**改了价格表，旧账单没变。**
已生成的账单不会重算。先结旧账再调价。见[价格表](../billing/rate-cards)。

**钱收到了但系统里对不上。**
先看[付款](../billing/payments)里有没有记录收款，再用[对账](../billing/reconciliation)把
银行流水配上。让客户转账时写参考号会省很多事。

**利润数字看着不对。**
利润 = 收入 − 承运成本 − 运营成本。成本漏记，利润就是虚高的。
见[报告与利润](../billing/reports)。

## 客户查件

**客户查不到单号。**
确认给客户的是**运单号**，不是你的内部单号。

**想用自己的域名做查件页。**
可以，见[公开查件页](../customers/tracking)。

## 对接

**想让自己的系统收到状态变更。**
在 **设置 → 自动化** 里配一条规则，见[自动化规则](../settings/automation)和
[开发者指南](/tms/webhooks)。

**要调接口。**
密钥在 **设置 → 机构 → API 凭证**，用法见[开发者指南](/tms/)。
