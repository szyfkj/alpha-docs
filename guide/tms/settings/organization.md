# 机构设置

**设置 → 机构** 是机构级的配置，分五个页签。

| 页签 | 管什么 |
|---|---|
| **常规** | 机构资料、Logo、运单号规则 |
| **单位** | 机构下属的单位 |
| **订阅** | 当前套餐，申请变更 |
| **承运商** | 你作为承运商时的配置 |
| **API 凭证** | 接口对接用的密钥 |

## 常规

机构名称、联系方式、Logo。Logo 支持 JPEG、PNG 或 PDF，**不超过 5MB**——格式或大小
不对会当场提示。

### 运单号规则

运单号怎么生成在这里配。改完保存提示"运单号规则已更新"。

:::warning
改号码规则只影响**之后**新建的运单，已有运单号不会变。频繁改会让单号看起来杂乱，
定下来就别动。
:::

## 单位

机构下属的单位。**配送规划**里选的**站点**就来自这里，站点地址是路线起点——
所以单位的地址要填全，**没有坐标的站点排不了路线**。

还有运单、用户或路线引用的单位不能删除，删除时会提示"仍有运单、用户或路线引用此单位，因此无法删除。"。先把它们改到别的单位，再删。

## 订阅

看当前套餐包含哪些功能。要换套餐就在这里提交申请，提示"订阅变更已提交，审核后
通知你"。

菜单看不到某个功能，多半是套餐里没有，见[界面导航](../getting-started/navigation)。

## API 凭证

对接接口用的密钥。也可以**重新生成凭证**。

:::danger
重新生成会**让现有凭证立即失效**，正在跑的对接会中断。系统会二次确认。
换之前先通知对接方。
:::

接口怎么用见[开发者指南](/tms/authentication)。
