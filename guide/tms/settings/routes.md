# 路线与货物类别

## 路线

**设置 → 路线** 管运单的走法——一条**路线**由若干**路段**组成。

页面顶部显示 **路线总数**、**路段总数** 和 **有路段的路线数**。

货跨区域走时不是一趟直达，而是按路段分段运输。系统会为每一段生成**子运单**，在
[运单详情](../waybills/detail)里能看到。

### 路段类型

每个路段有一个 **类型**：**本土** 或 **跨境**，在 **添加路段** / **编辑路段** 对话框里选，默认本土。路段列表也有 **类型** 这一列。原有的路段都算本土。

跨境路段上的运单使用跨境轨迹（装柜、清关等）：给这些运单[添加轨迹事件](../waybills/events#跨境运单)时，可选的是跨境的事件。运单自身所在的路段是跨境的，或者它所走路线里有任何一个跨境路段，就算跨境运单。

[导入运单](../waybills/import)时可以选路线；只有一条可选时系统自动选上。

### 每家机构用自己的路线

运单上的路线属于各自的机构。客户交给你的运单，你看到的是你自己的路线，不是客户的：

- 运单分配给你时，系统按 Alpha Cargo 平台为你的机构配置的规则，从你的路线里选一条。没有规则匹配时，这票运单在你这边没有路线。要配置规则，请联系 Alpha Cargo。
- 运单详情的 **路线：**、运单列表的 **路线** 筛选、自动化规则里的路线条件和计费，用的都是你自己的路线。所以给客户计费时，按你的路线设置的价格也能匹配上。
- 添加轨迹事件时判断是不是跨境运单，也看你自己的路线；你这边没有路线时，看客户那边的路线。

### 删除

删路线和删路段都会二次确认。删路段时会提醒**所有用到它的路线都会受影响**——
删之前先确认。

## 货物类别

**设置 → 货物类别** 把运单里的货分类，是一棵**类别树**，可以建父子层级。

点 **添加类别** 新建。没有类别时页面会提示先建第一个。

类别用在哪：

- 运单详情里可以就地改这票货的类别；
- 按类别做统计和分析。

删除类别会二次确认。

:::tip
类别树两三层足够。层级越深，录单的人越容易选错，统计反而更难看。
:::
