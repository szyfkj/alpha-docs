# 标签模板与集成

## 标签模板

**设置 → 标签模板** 管面单的版式。

点 **创建模板** 新建，进入可视化编辑器排版。模板列表里可以**设为默认**——
[打印标签](../waybills/labels)时没有特别指定就用默认那张。

已经是默认的再点一次会提示"该模板已是默认模板"。

:::warning
**默认模板删不掉**，会提示"无法删除默认模板"。要删它，先把另一张设为默认。
:::

删除模板会二次确认。

### 模板选择规则

同一页的 **模板选择规则** 决定每票运单用哪张模板打印：按运单的**路线**、**服务**和要交给的**[承运商](../partners/subcontractors)**来选。

点 **添加规则**，设条件，再选 **模板**。条件留为 **任意** 就匹配所有运单，但至少要设一个条件。条件完全相同的规则只能有一条。

一票运单命中好几条规则时，**命中条件最多的规则优先**；条件数相同时，路线优先于服务，服务优先于承运商。没有命中任何规则的运单用默认模板。还没有规则时，所有运单都用默认模板。

规则设了承运商时，还要选 **承运商打单方式**：

| 选项 | 效果 |
|---|---|
| **不影响承运商** | 只有你自己打单时用这张模板 |
| **承运商必须用此模板打单** | 承运商打这票货的面单时也用你的模板 |
| **承运商用自己的模板；交接时用此模板重贴** | 承运商照常用自己的模板，交接时用你的模板重新贴标 |

以前在承运商上配的专用模板已经自动转成了这样的规则。在[承运商](../partners/subcontractors#标签模板)详情里可以看到哪些规则用到了他。

## 第三方集成

**设置 → 集成** 配置第三方承运商和支付渠道的对接凭证。

页面上每个渠道是一张卡片。**套餐里没有的渠道显示为锁定状态**——需要开通才能配置，
见[界面导航](../getting-started/navigation)里讲的套餐门。

填的是对方给你的凭证。填好之后，相关的服务就能通过这个渠道下单了。

:::note
自己的系统要对接 TMS，是另一个方向——用 **设置 → 机构 → API 凭证** 里的密钥，
见[开发者指南](/tms/authentication)。
:::
