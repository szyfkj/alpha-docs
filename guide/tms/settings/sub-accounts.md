# 团队成员与权限

**设置 → 团队成员** 管机构里的同事账号，以及每个人能干什么。

## 列表

每个人显示状态（**启用** / **未启用** / **已暂停**）和已授予的权限。权限多的会折叠成
"**+N 更多**"。一个权限都没给的显示 **无权限**——这种账号登录后基本什么都看不到。

## 加一个人

新建账号填好邮箱等信息，系统发邀请邮件，对方点链接自己设密码，见
[注册与登录](../getting-started/signup)。

## 勾权限

权限按组划分，组下面还有更细的子权限。**勾组就是给这一组的全部**，也可以只勾其中几个
子项。

| 权限组 | 干什么的 | 子权限 |
|---|---|---|
| Scan | 扫码 | 按环节分：取件、入库、分拣、出库、配送 |
| Waybills | 建单、改单、取消、指定承运商 | — |
| Deliveries | 建配送、派司机 | 地址预处理 / 创建 / 分配 |
| Customer Service | 客户咨询与工单 | 客户渠道 / 司机渠道 |
| Partner Management | 合作伙伴 | 承运商管理 / 司机 |
| System Settings | 系统设置 | 用户 / 机构 / 自动化 / 服务区域 / 标签模板 |
| Billing | 账单菜单及其日常工作 | 价格表 / 付款 / 钱包调整 |

:::note 这个界面是英文的
权限名称**不跟随界面语言**，中文界面下看到的也是 `System Settings`、
`Wallet Adjustment` 这样的英文。上表给出对照。
:::

## 几个要想清楚的地方

**扫码权限按环节给。** 分拣员只给 Scan → 分拣，他在手机扫描页的事件类型下拉里
就只能看到分拣。这正是[司机扫码](../driver/scan)里"下拉只有一项"的原因——
不是故障。

**Billing 组是菜单的总开关。** 不给这一组，整个账单菜单在菜单条上都不出现。

**钱包调整单列，是有道理的。** 它允许**不经过任何收款直接改客户的预付余额**。
给这项权限前想清楚。

**机构所有者拥有全部权限**，不需要也不能在这里勾选。

**所有者可以编辑自己的资料。** 机构所有者在列表里对自己点 **编辑**，可以修改姓名、电话和机构单位，点 **更新用户** 保存。权限区所有选项都已勾选并变灰，下方提示"所有者拥有全部权限，无法修改"；保存不会改动所有者的权限。

**其他人不能改自己的账号。** 不是所有者的成员编辑自己时，保存会被拒绝，提示"您不能在此修改自己的账户，请联系机构所有者"。请让机构所有者来改。

## 停用和暂停

人员离职**停用**账号，不要删——他经手的运单、配送和操作记录还挂在这个账号上。
