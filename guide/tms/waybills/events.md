# 添加轨迹事件

正常情况下轨迹是司机扫码扫出来的。但总有扫不上的时候——手机没信号、单子漏扫、
第三方承运商只给你打电话报了个口信。这时候在后台手工补一条。

## 怎么加

1. 在运单列表**勾选**要补状态的运单，可以一次勾多票。
2. 点 **分配 → 添加轨迹事件**。
3. 填写：

| 字段 | 必填 | 说明 |
|---|---|---|
| **事件类型** | 是 | 状态词，清单见[运单状态参考](./statuses) |
| **日期和时间** | 是 | 事件**实际发生**的时间，不是你录入的时间 |
| **位置** | 否 | 地点文字描述 |
| **备注** | 否 | 补充说明，比如"客户电话确认已收" |
| **签收凭证照片** | 否 | 最多 5 张 |

4. 点 **添加事件**。

勾了几票就给几票各加一条相同的事件。

<Staging source="tms#188">

**照片在事件保存之后才上传。** 点 **添加事件** 后先保存事件，再上传照片；上传前每张照片会被缩小到最长边 1600 像素（JPEG），大照片也能传上去。

如果照片没传上去，事件照样保存，提示会写明"事件已保存，但照片上传失败。请在该事件的签收凭证部分重新添加。"这时打开运单详情，在[轨迹时间线](./detail#轨迹时间线)里找到这条事件，在它下面的照片区重新添加即可。在那里添加失败会提示"照片未上传"，再试一次就行。

## 跨境运单

运单走的是[跨境路段](../settings/routes#路段类型)时，**事件类型** 下拉框换成跨境的事件。每个跨境事件同时记为一个普通状态，所以运单和包裹的状态照常变化：

| 跨境事件 | 说明 | 运单状态 |
|---|---|---|
| **已接** | 包裹已揽收，准备跨境运输 | 已接 |
| **已装柜** | 包裹已装入集装箱 | 运单已分拣 |
| **出口清关完成** | 包裹已完成出口清关 | 在运输中，包裹离开分拨中心 |
| **已离港** | 包裹已发往目的国 | 在运输中，包裹离开分拨中心 |
| **已到港** | 包裹已到达目的国 | 在运输中，包裹进入分拨中心 |
| **进口清关完成** | 包裹已完成进口清关 | 运单已分拣 |
| **已送达** | 包裹已送达 | 已送达 |

另外还有 **配送失败**、**配送异常**、**重新安排** 两个 **返回**（一个表示正在退回，一个表示已退回），和本土运单一样。选 **已送达** 时同样可以上传签收凭证照片。

运单详情的[轨迹时间线](./detail)和[公开查件页](../customers/tracking)显示跨境事件的名称和说明，比如"出口清关完成"，而不是它对应的状态。

本土运单和跨境运单不能一起加：同时勾了两种时，对话框提示"请只选本土运单或只选跨境运单，两者的轨迹不同。"，**添加事件** 按钮不可用。分两次勾选即可。

</Staging>

## 注意

- **时间填实际发生的时间。** 客户看到的轨迹按这个时间排序，填成当前时间会让轨迹
  顺序乱掉。
- **事件只增不改。** 补错了只能再补一条正确的盖过去，时间线上两条都在。所以补之前
  先确认。
- 司机的送达确认是另一条路径，走 LINE 完成，见[送达确认](../driver/pod)。
