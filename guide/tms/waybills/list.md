# 运单列表与筛选

**运单** 页是登录后的默认页，也是日常用得最多的一页。

## 页面怎么分块

左边三分之一是运单列表，右边是选中那一票的详情和轨迹。点列表里的一条，右边跟着变。

列表左上角显示 **运单** 和总条数，右上角是 **导出** 和 **导入** 两个按钮。

:::tip
列表里每条前面有勾选框，**点一条是看详情，勾一条是准备批量操作**——两件事。
:::

## 搜索和筛选

顶部搜索框直接按运单号、收件人等关键词搜。点 **筛选**（窄屏上是 **更多**）展开完整
条件：

| 条件 | 说明 |
|---|---|
| 服务区域 | 按派送区域收窄 |
| 站点 | 按出发/归集站点收窄 |
| 客户 | 把货交给你的上家 |
| 承运商 | 你交出去的下家 |
| 寄件账户代码 | 按寄件人账户的代码精确找 |
| 状态 | 可多选 |
| 服务 | 按卖的服务收窄 |
| 路段 | 选 **仅主运单** 可以把分段产生的子运单排除掉 |
| 日期 | **从** / **至** 一个时间范围 |
| 仅显示未分配 | 只看还没派出去的 |

改完条件点 **搜索**；**清除** 把条件清空。

## 批量操作

勾中一条或多条之后，列表上方会出现一条操作栏，显示勾了几票，右边是 **分配** 下拉：

| 操作 | 做什么 |
|---|---|
| **指定承运商** | 把这些运单交给下家承运，见[指定承运商](./subcontract) |
| **添加轨迹事件** | 手工补一条物流状态，见[添加轨迹事件](./events) |
| **打印标签** | 生成面单 PDF，见[打印标签](./labels) |
| **取消运单** | 作废这些运单 |
| **合并运单** | 并成一票，见[合并运单](./consolidate)——条件不满足时这项不出现 |

操作栏下面还会实时汇总勾中运单的**票数、总重、体积和最大尺寸**——排车前估算车能不能
装下，看这里最快。

点 **清除选择** 取消勾选。

## 导出

**导出** 按钮把当前筛选结果导出为 Excel 文件。单次导出有条数上限，超了会提示你先收窄条件。

导出文件里有哪些工作表、哪些列，由平台管理员为你的机构配置的**导出模板**决定。机构只有一个模板时，点 **导出** 直接开始；有多个时，先弹出 **导出运单** 对话框，在 **导出模板** 里选一个再点 **导出**。还没有配置模板时会提示"本机构未配置导出模板，请联系平台管理员。"

导出是后台任务，不用守着页面。导出按钮旁边可以看历史导出记录，任务跑完在那里下载。

## 运单从哪来

列表里的运单有三个来源：

1. **导入**——批量上传表格，见[导入运单](./import)；
2. **接口推送**——你或你的客户的系统直接推进来，见[开发者指南](/tms/waybills)；
3. **分段拆出的子运单**——一票货跨区域走时系统自动生成。

:::note portal 里没有"新建运单"按钮
运单是批量业务，界面上不提供一票一票手工录入的表单。只有一票货要录的话，用
[导入运单](./import)传一行也可以。
:::
