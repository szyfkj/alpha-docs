# 仓库

**设置 → 仓库** 管组织里的仓库地点。列表显示每个仓库的名称、编码、地点、状态、联系方式和备注，可以按名称、编码或城市搜索，按状态和国家/地区筛选。

## 添加或编辑仓库

点 **添加仓库**，填好信息后点 **创建仓库**。改已有的仓库用同一个表单，点 **保存**。

表单上标 `*` 的是名称、编码、地址、城市和国家/地区。**省/州**、**邮政编码**、**电话** 和 **邮箱** 没有标 `*`，但同样要填：留空的话保存会失败，提示里不会说是哪一栏。只有 **备注** 可以不填。

<Staging source="wms#13">

除 **备注** 外，所有字段都标 `*`，提交前就在表单里检查。漏填的字段会标红，下面显示"此项为必填项"，表单不会提交；内容过长或邮箱格式不对也会在对应字段下提示。编辑仓库时同样如此。
