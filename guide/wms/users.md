# 用户与停用账号

管理员在 **设置** → **用户**（**用户管理**）里管理组织的用户。每个用户有一个状态：**启用**、**停用** 或 **已暂停**。

## 收回某人的访问权限

WMS 不能删除用户。要让某人不能再登录，编辑这个用户，把 **状态** 改成 **停用** 或 **已暂停**，然后保存。之后：

- 他在网页控制台、手机网页版和手机 App 上都无法登录，登录页提示“您的账号已被停用，请联系管理员。”
- 他已经打开的会话在下一次加载页面时被退出，回到登录页并显示同样的提示。
- 用他的账号调用的接口会被拒绝。

把状态改回 **启用**，他就能重新登录。用户的记录和历史操作都会保留。

## 不能停用的账号

以下账号不能改成 **停用** 或 **已暂停**，保存时会报错：

- 你自己的账号；
- 组织的所有者和内置的管理员账号。

## 权限变化

角色权限里不再有 **删除用户** 这一项。以前授予过这项权限的角色，权限列表里也不再显示它。
