# 拣货

**拣货** 任务把一批包裹从各自的货架拣出来，集中放到一个目标库位。拣货结束后，WMS 自动为拣到的包裹生成一个合包任务。

## 创建拣货任务

在网页后台的 **工作流** 页面点 **创建作业流程**，类型选 **拣货**，勾选要拣的包裹，然后点 **创建作业流程**。勾选 **是否拆包合箱** 时，这个设置会带到拣货结束后生成的合包任务里。

新任务出现在作业流程列表里（类型筛选里也有 **拣货**），作业员在手机上执行它。

## 在手机上拣货

在手机的 **仓库作业员** 首页 → **工作流操作** 里点 **拣货**，打开一个拣货任务。顶部显示进度“已拣 x / y”，下方的 **包裹** 清单按库位排列，列出每个包裹现在所在的库位。拣货分三步：

1. **暂存库位**：扫描或输入一个库位（拣货车或暂存位，仓库里任何库位都可以），点 **开始拣货**。拣到第一个包裹之后就不能再换暂存库位。
2. **拣货**：逐个扫描包裹。每扫到一个，包裹立即移到暂存库位，进度随之增加。不在这个任务里的包裹会被拒绝（“… 不在这个拣货任务里”），还没入库到这个仓库的包裹也一样。
3. **目标库位**：扫描或输入目标库位（任何库位都可以），点 **完成拣货**。所有已拣包裹移到目标库位，任务结束，手机提示“拣货完成，已生成合包任务”。

每扫一次进度都会保存，换一台手机打开同一个任务可以接着拣。

## 提前结束

有包裹找不到时，可以在第 2 步点 **提前结束**。至少要拣到 1 个包裹，并在 **原因** 里写明为什么没拣到，然后照常扫描目标库位、点 **完成拣货**。点 **返回继续拣货** 可以回到第 2 步。

提前结束时，生成的合包任务只包含拣到的包裹。没拣到的包裹和原因记在拣货任务里，并显示在合包任务的顶部：“拣货提前结束：有 n 个包裹没找到”，下面列出包裹号和原因。

## 拣货后的合包任务

拣货结束后生成的合包任务出现在 **合并** 里，从 **收集核对** 开始，包裹已经在目标库位上，不再有先移库的一步。在网页后台创建的拣货生成 **合包并入库** 任务。

## 合包任务不再先移库

新建的 **合包并入库** 和 **合并并出库** 任务（包括在网页后台创建的）去掉了开头的移库步骤：

- **合包并入库**：合并 → 移库；
- **合并并出库**：合并 → 出库。

已经创建的任务保持原来的步骤。
