# 拣货

**拣货** 任务把一批包裹从各自的货架拣出来，集中放到一个目标库位。拣货结束后，WMS 自动为拣到的包裹生成一个合包任务。

## 创建拣货任务

在网页后台的 **工作流** 页面点 **创建作业流程**，类型选 **拣货**，勾选要拣的包裹，然后点 **创建作业流程**。勾选 **是否拆包合箱** 时，这个设置会带到拣货结束后生成的合包任务里。

新任务出现在作业流程列表里（类型筛选里也有 **拣货**），作业员在手机上执行它。

## 在手机上拣货

在手机的 **仓库作业员** 首页 → **工作流操作** 里点 **拣货**，打开一个拣货任务。顶部显示进度“已拣 x / y”，下方的 **包裹** 清单按库位排列，列出每个包裹现在所在的库位。拣货分三步：

1. **暂存库位**：扫描或输入一个库位（拣货车或暂存位，仓库里任何库位都可以），点 **开始拣货**。拣到第一个包裹之后就不能再换暂存库位。
2. **拣货**：逐个扫描包裹。每扫到一个，包裹立即移到暂存库位，进度随之增加。不在这个任务里的包裹会被拒绝（“… 不在这个拣货任务里”），还没入库到这个仓库的包裹也一样。
3. **目标库位**：扫描或输入目标库位（任何库位都可以），点 **完成拣货**。所有已拣包裹移到目标库位，任务结束，手机提示“拣货完成，已生成合包任务”。

每扫一次进度都会保存，换一台手机打开同一个任务可以接着拣。

## 提前结束

有包裹找不到时，可以在第 2 步点 **提前结束**。至少要拣到 1 个包裹，并在 **原因** 里写明为什么没拣到，然后照常扫描目标库位、点 **完成拣货**。点 **返回继续拣货** 可以回到第 2 步。

提前结束时，生成的合包任务只包含拣到的包裹。没拣到的包裹和原因记在拣货任务里，并显示在合包任务的顶部：“拣货提前结束：有 n 个包裹没找到”，下面列出包裹号和原因。

## 拣货后的合包任务

拣货结束后生成的合包任务出现在 **合并** 里，从 **收集核对** 开始，包裹已经在目标库位上，不再有先移库的一步。在网页后台创建的拣货生成 **合包并入库** 任务。

## 合包任务不再先移库

新建的 **合包并入库** 和 **合并并出库** 任务（包括在网页后台创建的）去掉了开头的移库步骤：

- **合包并入库**：合并 → 移库；
- **合并并出库**：合并 → 出库。

已经创建的任务保持原来的步骤。

## TMS 发来的合包按路线先拣货

TMS 把一票主运单的合包交给 WMS 时，WMS 按主运单的 TMS 路线选用合包工作流。每条路线用哪个工作流在网页后台 **设置 → API 密钥** 的 **按路线合包** 里选，没有列出的路线用默认的 **拣货-合包**。

- **拣货-合包**、**拣货-合包-移库**（包括没有列出的路线）：先生成一个拣货任务，出现在手机的 **拣货** 里，按上面的三步拣货。拣货完成后生成合包任务，从 **合包** 开始，没有先移库的一步：
  - 拣货-合包：合包 → 上架；
  - 拣货-合包-移库：合包 → 上架 → 同仓移库。
- **合包**、**合包-移库**：直接生成合包任务，不经过拣货。

拣货期间 TMS 追加的包裹会加进这个拣货任务。合包步骤完成时 WMS 就通知 TMS，之后的移库不影响 TMS 出库。已经创建的任务保持原来的步骤。

## 移库是单独的移库任务

在 **拣货-合包-移库** 和 **合包-移库** 路线上，移库不再是合包任务里的一步，而是合包任务完成后单独生成的移库任务：

- 拣货-合包-移库：合包任务是 合包 → 上架；
- 合包-移库：合包任务只有 合包。

合包任务完成时，WMS 为每个新箱子生成一个待处理的移库任务，名称是“Relocate &lt;箱号&gt; - TMS outbound &lt;主运单号&gt;”。它出现在手机 **移库** 页面的 **待移库任务** 里，显示箱子现在的库位；在网页后台的 **工作流** 页面里，它的类型是 **移动库位**，状态 **待处理**。作业员扫描箱子和目标库位，箱子移过去后，移库任务就完成了。

完成合包任务不再连带完成移库。在这之前创建的合包任务保持原来的步骤，移库仍在合包任务里。

</Staging>

## 合包路线也上架

**合包** 和 **合包-移库** 路线的合包任务在合包之后多了一步 **上架**，和 **拣货-合包** 一样把新箱子放到库位上：

- 合包：合包 → 上架；
- 合包-移库：合包 → 上架，合包任务完成后再单独生成移库任务（见上一节）。

合包步骤完成时 WMS 就通知 TMS，上架不影响 TMS 出库。**设置 → API 密钥** 的 **按路线合包** 里列出的步骤也随之更新。已经创建的合包任务保持原来的步骤。

</Staging>
