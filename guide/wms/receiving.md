# 入库收货

仓库作业员在手机上收货：**仓库作业员** 首页 → **入库**（接收、测量包裹并放入仓储位置）。选好仓库，扫描或输入运单号，填写尺寸、重量和照片，最后在 **库位** 里扫描或输入要放入的库位编码，点 **接收包裹**。

<Staging source="wms#16">

**仓库工人** 以外的角色（比如 **经理**、**管理员**）打开 **入库** 时，如果只有一个仓库可选，**仓库** 会自动选好：账户只分配了一个仓库时选它；没有分配或分配了多个时，如果只能看到一个仓库，就选那个仓库。同时会填上这台设备上次在该仓库用过的库位。需要时仍可以换成别的仓库；有多个仓库可选时，仍需手动选择。

</Staging>

<Staging source="wms#23">

## 测量结果同步到 TMS

仓库接入了 TMS 时，点 **接收包裹** 后，收货时填的重量和尺寸会写到 TMS 里这个包裹上，覆盖原来的值，客户下单时已经填过的也一样。TMS 会按新的重量和尺寸重新算运单的合计和费用。在 TMS 的运单详情里，[包裹](../tms/waybills/detail.md#包裹) 区块显示的就是仓库测量的值。

只覆盖收货时填了的项，没填的项保持不变；什么都没填时不改动。多件的运单，每件写各自的值。写入失败时（比如 TMS 暂时连不上），收货照常完成，不会报错。

</Staging>

## 能放入哪些库位

接收包裹只能放入同时满足以下两点的库位：

- 类型是 **料箱**；
- 状态是 **可用** 或 **已占用**。

其他类型的库位（比如 **货架**，也是新建库位的默认类型）以及 **已预留**、**维护中** 的库位不能用来收货。需要放进某个库位时，请管理员把它的类型改成 **料箱**，或把状态改回 **可用**。

库位编码在所选仓库里找不到时，**库位** 下方提示“未知库位：B-01-01”。

<Staging source="wms#11">

库位存在但不能用来收货时，**库位** 下方的提示和点 **接收包裹** 后的报错会说明原因，不再显示“未知库位”：

- 类型不对：“B-01-01 是货架库位，接收包裹只能放入料箱库位。”
- 状态不可用：“B-01-01 当前维护中，无法接收包裹。”

只有所选仓库里确实没有这个编码时，才提示“未知库位”。

</Staging>

## 扫描入库

只需告诉 TMS 包裹已到仓、不必测量和上架时，用 **仓库作业员** 首页 → **快捷操作** → **扫描入库**（快速扫描——通知 TMS 包裹已到达）。扫描或输入包裹号，点 **确认入库**，成功后提示“C0MC14661154 已入库”，TMS 里该包裹会记下到达中转仓的事件。包裹需要先在本仓库用 **入库** 收过货。

<Staging source="wms#19">

**扫描入库** 不再要求包裹先在本仓库收过货。本仓库没有收过的包裹，会到你的仓库所关联的 TMS 组织里查找（账户没有分配仓库时，比如所有者或管理员，查找公司所有仓库关联的 TMS 组织）：

- 号码是 TMS 的包裹号、外部单号或子包裹号：通知该包裹已到达。
- 号码是运单号，运单只有一个包裹：通知这个包裹已到达。
- 号码是运单号，运单有多个包裹：不入库，提示“C0MC14661154 是含 3 个包裹的运单，请扫描包裹标签”。请改扫包裹标签。
- 哪里都找不到：提示“在本仓库和 TMS 中都找不到 C0MC14661154，请检查单号”。
- 你的仓库还没有关联 TMS 组织：提示“你的仓库未关联任何 TMS 组织，请管理员在 设置 → API 密钥 中关联”。

快速扫描不会在本仓库生成收货记录；需要测量、拍照和上架时，仍用 **入库**。报错提示会按界面语言显示。**扫描出库** 仍只能用于本仓库收过的包裹。

</Staging>
