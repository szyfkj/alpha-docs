# 营销培训手册

本手册是营销部门的培训教材，说明如何在公司的营销系统中与智能体协作，完成从调研、选题、制作、发布到效果评估和付费推广的全部工作。

营销系统是公司智能体工作平台（Paperclip）中的“营销”页面。系统中，可重复的工作由智能体完成：搜集素材、提出选题、撰写简报和脚本、检查原始素材、剪辑视频、统计数据。需要判断和承担责任的工作由人完成：批准项目设定、选定题目、审核要发出的内容、签订合同、付款。

## 适用读者

| 读者 | 在系统中的角色 | 主要工作 |
|---|---|---|
| 业务负责人 | 老板 | 批准项目设定及其每一次修改 |
| 营销主管 | 负责人 | 每周选定题目、确认简报、决定达人合作 |
| 内容审核人员 | 审核人 | 批准或退回脚本和成品 |
| 运营专员 | 专员 | 拍摄、上传素材、发布内容、记录数据和付款 |
| 语言检查人员 | 语言检查人 | 检查某一种外语脚本的用语 |

一个人可以同时担任多个角色。角色由项目设定中的“人员”一项指定，见[项目设定](./settings.md)。

## 学习方式

1. 所有人先阅读入门部分的两章。
2. 按角色阅读相关章节，对应关系见[每周工作安排](./weekly.md)中的角色表。
3. 每章末尾有练习，大多数通过查看演示项目完成。
4. 全部学完后完成[培训练习与自测](./exercises.md)中的综合练习。

## 演示项目

系统带有一个演示项目 **Hill Coffee**：一家虚构的咖啡烘焙坊，已经走完全部环节。本手册的截图均来自该项目，其中的账号、达人和数字都是虚构的。

演示项目不连接任何真实平台，也不会把任务交给智能体。

演示项目由全体成员共用，其中的改动无法恢复。各章的练习以查看和书面作答为主；标有“练习项目”的练习需要保存数据，请在培训负责人指定的练习项目中完成，不要在演示项目或正式项目中进行。

在“营销”页面顶部的项目下拉框中选择 **Hill Coffee (demo)** 即可进入。如果列表中没有该项目，请公司的所有者或管理员载入。

## 页面语言

页面右上角可以切换中文、英文和泰文。本手册使用中文界面的原词，并以引号或粗体标出，例如“选题与简报”、**选定**。

团队的工作语言是中文：备注、分析、简报和报告都用中文书写。发布内容使用的外语文本，在系统中都附有中文译文，不懂该语言的成员可以据此判断。
