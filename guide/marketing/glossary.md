# 术语表

术语按主题排列，写法与中文界面一致。

## 流程与角色

| 术语 | 含义 |
|---|---|
| 项目 | 为一个品牌在一个市场做营销的单位；有自己的设定、素材库、选题和费用记录 |
| 项目设定 | 智能体工作所依据的全部信息，以版本保存，由老板批准 |
| 智能体 | 在系统中执行任务的 AI：调研员、内容制作、分析员、达人发掘、素材审核、视频剪辑 |
| 老板 | 批准项目设定的人 |
| 负责人 | 每周选题、确认简报、决定达人合作的人 |
| 审核人 | 批准或退回脚本和成品的人 |
| 专员 | 拍摄、发布、记录数字和付款的人 |
| 语言检查人 | 检查某一种外语脚本用语的人 |
| 逐条审核、抽查 | 两种审核方式；连续 20 件一次通过后由前者改为后者 |
| 授权表 | 公司规定每类花费由哪个岗位批准的表 |

## 内容

| 术语 | 含义 |
|---|---|
| 市场素材库 | 同行和相关账号做得好的内容 |
| 客户原话库 | 客户用自己的话说的内容 |
| 高于常规（倍） | 一条内容的播放量相对其作者平时水平的倍数 |
| 内容主题 | 项目反复讲的 3–5 个话题，各占一定比例 |
| 选题 | 一条内容的题目，注明所属主题和依据的素材 |
| 简报 | 动笔或开拍前确定的要点：制作方式、平台、形式、角度、开头、时长、引导动作 |
| 角度 | 一条内容的核心说法 |
| 开头 | 内容的前几秒 |
| 引导动作 | 结尾要求观众做的一件事 |
| 可用说法、禁用说法 | 项目设定中允许和禁止使用的表述 |
| 脚本 | 一条内容的完整文字，使用发布平台的语言 |
| 中文回译 | 外语脚本的中文译文，供不懂该语言的成员判断 |
| 成品 | 可以发布的最终内容 |

## 制作

| 术语 | 含义 |
|---|---|
| 制作方式 | AI 生成；实拍 + AI 剪辑；达人制作；外包或团队 |
| 原始素材 | 未经剪辑的拍摄片段 |
| 素材审核 | 剪辑前对照脚本和简报检查原始素材 |
| 拍摄 | 为多条已批准的脚本集中拍摄的一天及其片段 |
| 片段 | 一个拍摄文件 |
| 台词片段 | 含有脚本台词的片段 |
| 空镜 | 不含脚本台词的画面，本次拍摄的任何成品都可以使用 |
| 整理 | 素材审核智能体说明每个片段的类别、所属脚本和缺少的句子，并为计划外的内容提出制作方案 |
| 制作方案 | 素材审核智能体根据拍摄中计划外的内容提出的成品清单，由负责人确认一次 |
| 按素材写成 | 由制作方案产生的简报和脚本：台词是现场实际说的话，负责人确认即已批准 |
| 转写 | 片段中所说内容的文字记录，带时间 |
| 剪辑参考 | 指定给一条视频参照其剪法的素材库视频，最多三条 |
| 学剪辑 | 剪辑智能体测量并记录一条视频的剪法 |
| 剪辑说明 | 剪辑智能体对每处处理及其理由的说明 |
| 安全区 | 画面中不会被平台按钮遮挡的区域 |

## 效果与花费

| 术语 | 含义 |
|---|---|
| 时间点 | 记录数字的固定时间：发布后 1 小时、24 小时、72 小时、7 天、28 天 |
| 曝光 | 内容被展示的次数 |
| 3 秒留存 | 看到内容的人中观看超过 3 秒的比例 |
| 看完率 | 看完整条内容的比例 |
| 生意 | 项目设定中定义的业务事件：咨询、注册或订单 |
| 追踪链接、追踪码 | 把生意追溯到具体内容或达人的标识 |
| 爆款 | 互动排在本账号前列并带来生意的内容 |
| 受欢迎但没成交 | 互动排在前列但没有带来生意的内容 |
| 推广 | 为一条已发布的内容付费增加曝光 |
| 加投 | 为表现突出的推广追加预算并延长天数 |
| 广告账户限额 | 在广告平台账户中设定的花费上限 |
| Spark Ads 授权码 | 达人为允许他人推广其视频而生成的代码，有到期日 |
| 待验证的假设 | 项目认为有效但尚未证实的做法 |
| 复盘 | 把自己的内容及其数字放回素材库分析，并提出修改假设的建议 |

## 达人与活动

| 术语 | 含义 |
|---|---|
| 达人 | 拥有自己账号、与项目合作发布内容的人 |
| 播放中位数 | 达人近期作品的常规播放量 |
| 互动率 | 点赞、评论和转发相对播放量的比例 |
| 营销活动 | 一轮有目标、起止日期、预算和优惠内容的集中推广 |
| 日常内容 | 不属于任何活动的内容 |
| demo | 达人在发布前发给团队审核的视频 |
| 无 demo 放行 | 负责人填写原因后，允许未经 demo 审核的视频登记 |
| 达人跟进表 | 团队自行记录活动中达人及其阶段的表格 |
