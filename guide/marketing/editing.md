# 剪辑与成品

## 学习目标

学完本章，应能：

- 说明剪辑智能体如何工作，以及它遵循的规则；
- 为一条视频指定剪辑参考；
- 阅读剪辑说明，并用日常语言提出修改意见。

## 剪辑由智能体完成

团队中不需要有人会剪辑。原始素材通过审核后，剪辑智能体收到任务，依次：

1. 查看每个片段的长度、画面和停顿；
2. 取得带时间的转写文字，与已批准的脚本对应；
3. 决定保留哪些段落、字幕和画面文字放在哪里；
4. 渲染视频，检查开头、字幕位置和引导动作，必要时修正后再渲染；
5. 提交成品，并附**剪辑说明**。

成品提交后进入“审核”页，由审核人批准或退回。退回的成品直接回到剪辑智能体。

剪辑智能体不发布内容，不登录账号，不联系达人，也不在成品中加入音乐：配乐在发布时从平台的商用音乐库添加，剪辑说明会建议适合的类型。

## 剪辑规则

剪辑智能体对竖屏短视频遵循以下规则。剪辑说明中以【】标出每处处理所依据的规则，便于团队逐步熟悉。

| 规则 | 内容 |
|---|---|
| 开头即重点 | 前 1–2 秒决定观众是否停留。从简报的开头句或最有力的画面开始，不以问候或标志开头；同时把要点以文字显示在画面上 |
| 删掉空白 | 剪掉句子之间超过约 0.3 秒的停顿、口头语、说错的部分和多余的遍数 |
| 每 2–4 秒有变化 | 画面每 2–4 秒有一次变化：换镜头、放大、插入空镜或文字卡 |
| 字幕必须有 | 多数人静音观看。使用脚本的原文，每屏一至两行，字号大、对比度高，关键词突出 |
| 安全区 | 人脸、字幕和文字避开平台按钮：不放在画面顶部约 15%、底部约 25% 和右侧约 15% |
| 声音清楚 | 人声最响且音量均匀；不在成品中使用有版权的歌曲 |
| 画面配合内容 | 说到某样东西时，如果素材中有，就展示它 |
| 结构 | 开头吸引注意，中间提供证明或演示，结尾给出答案，最后 2–3 秒显示唯一的引导动作 |
| 越短越好 | 在简报规定的时长内，能说清要点的最短版本最好 |
| 格式 | 竖屏 9:16，1080×1920 |

项目设定中的说话风格、禁用词和标注要求，适用于画面上的每一个字。

## 剪辑参考

可以为一条视频指定参考：在选题详情的“剪辑参考”点击**选择**，从市场素材库中选最多三条带链接的视频。剪辑智能体会按它们的剪法处理：镜头长度、首个剪辑点的时间、字幕的样式和位置、结尾方式。

不指定时，剪辑智能体自己从已学过剪辑的爆款中挑选同平台的视频；没有合适的，就只按上述规则剪辑，并在剪辑说明中写明。

### 学剪辑

在市场素材库中对一条视频点击**学剪辑**，剪辑智能体会测量它的剪法并保存为“剪辑分析”：时长、首个剪辑点、平均镜头长度、每 10 秒的剪辑点数、最长停顿，以及开头画面、字幕、画面文字、镜头运动、插入画面、声音和结尾的描述。

已学过的视频标有“已学剪辑”，可以直接用作参考。剪辑智能体每周也会主动学习若干条表现突出的视频。

## 剪辑说明

剪辑说明用中文书写，面向没有剪辑经验的人。示例：

```text
成品：27 秒 · 9:16 · Instagram Reel（简报要求 25–30 秒）
参考：某账号《……》：平均镜头 1.8 秒、首个剪辑点 0.6 秒。
本条平均镜头 2.0 秒、首个剪辑点 0.7 秒；素材是单机位，所以多用放大来代替换镜头。

改动：
- 0:00 从“这是我给你带的”开始，删掉了前面 3.2 秒的准备动作。【开头即重点】
- 全片删掉 11 处停顿和 2 次重说，共 9 秒。【删掉空白】
- 0:04、0:11、0:19 同一机位接下一句时放大到 115%。【每 2–4 秒有变化】
- 字幕用脚本原文，白字黑边，放在画面中下部、平台按钮之上。【字幕必须有】【安全区】

没做到 / 需要人决定：
- 素材里没有伴手礼的特写，0:08 处只能用中景。【画面配合内容】
- 发布时建议配轻快的背景音乐，音量压低。

下次拍摄建议：
- 每句之间停一秒再说下一句；说错时整句重来。
```

阅读时重点看两部分：

- **没做到 / 需要人决定**：这些是素材的限制或需要你判断的事项。
- **下次拍摄建议**：转给拍摄人员，可以减少以后的同类问题。

## 提出修改意见

审核成品时不需要使用剪辑术语，直接描述观众的感受即可。剪辑智能体按下表理解常见的说法：

| 审核人的说法 | 通常的原因 | 剪辑智能体的处理 |
|---|---|---|
| 开头太慢，没抓住人 | 重点出现得晚 | 从开头句开始，删掉之前的内容，把要点显示在画面上 |
| 字幕看不清 | 字太小、对比度低，或被平台按钮挡住 | 放大，加描边或底框，移入安全区，减少每行字数 |
| 太快，跟不上 | 停顿剪得过紧，变化过多 | 句间多留 0.2–0.3 秒，减少放大 |
| 中间无聊，拖沓 | 内容重复，静止镜头过长 | 删掉重复的句子，每 2–3 秒加入变化，缩短 |
| 声音小，有杂音 | 音量低或不均匀 | 提高并均衡人声，降低或去掉配乐 |
| 太像广告 | 画面文字过多，推销过于直接 | 减少文字卡，使用自然的结尾和较缓和的引导动作 |
| 不像我们 | 偏离项目的说话风格 | 重新对照设定中的规则和范文 |

意见含义不明确时，剪辑智能体会在任务中给出两个具体方案请你选择，而不是猜测。

## 非视频成品和手动提交

AI 生成的图文由内容制作智能体直接提交成品。外包或团队制作的成品，以及项目没有剪辑智能体时，由专员在选题详情中点击**提交成品**，填写成品链接；包含 AI 生成素材时勾选相应选项。

## 练习

1. 阅读本章的剪辑说明示例，指出哪一项需要人作决定，哪一项应当转告拍摄人员。
2. 观看一条你认为剪得好的同行视频，用本章的规则说明它好在哪里。
3. 用日常语言为一条视频写三条修改意见，并对照上表判断剪辑智能体会如何处理。

## 本章要点

- 剪辑由智能体按固定规则完成，并说明每处处理的理由。
- 可以指定最多三条参考视频。
- 修改意见用观众的感受来表达即可。
