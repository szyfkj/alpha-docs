# 页面与日常入口

## 学习目标

学完本章，应能：

- 找到自己每天需要处理的事项；
- 说出每个页签的用途；
- 查看智能体正在执行的任务。

## 进入营销页面

1. 登录公司的智能体工作平台。
2. 在左侧菜单选择“营销”。
3. 在页面顶部的下拉框中选择项目。未启用营销的项目名称后标有“未启用营销”，由公司的所有者或管理员启用。

## 每天从“等你处理”开始

“运作方式”页顶部的“等你处理”列出当前需要你本人处理的事项，按你在该项目中的角色筛选。每一行右侧的**打开**直接跳到对应页面。

常见事项及负责的角色：

| 事项 | 角色 |
|---|---|
| 一个新版本的项目设定待批准 | 老板 |
| 若干选题待选定或放弃 | 负责人 |
| 若干简报待确认 | 负责人 |
| 若干脚本或成品待审核 | 审核人 |
| 若干外语脚本待检查语言 | 语言检查人 |
| 若干达人 demo 待审核 | 审核人 |
| 若干爆款可以申请推广 | 负责人 |
| 若干计划付款待批准 | 负责人 |
| 若干款项待支付并标记已付 | 专员 |
| 若干内容缺少数据 | 专员 |
| 若干达人帖子需要 Spark Ads 授权码 | 专员 |

列表下方的“等其他人处理”显示其他角色的待办，便于了解工作卡在哪里。

页签名称旁的数字是该页待处理事项的数量。

## 页签

| 页签 | 用途 | 对应章节 |
|---|---|---|
| 运作方式 | 待处理事项、各环节进度、审核方式、本月花费 | 本章 |
| 项目设定 | 智能体工作所依据的信息及其版本 | [项目设定](./settings.md) |
| 素材库 | 市场素材库和客户原话库 | [调研与素材库](./research.md) |
| 选题与简报 | 选题看板；每个选题的简报、脚本、素材和成品 | [选题与简报](./ideas.md) |
| 拍摄 | 为多条脚本集中拍摄的一天及其片段 | [集中拍摄](./shoots.md) |
| 审核 | 待审核的脚本和成品 | [脚本与审核](./review.md) |
| 效果 | 已发布内容的数字和判定 | [效果与爆款判定](./results.md) |
| 费用 | 推广和付款记录 | [推广与费用](./boosts.md) |
| 营销活动 | 有目标、起止日期和预算的集中推广 | [营销活动](./campaigns.md) |
| 达人 | 达人名单及合作阶段 | [达人合作](./creators.md) |

## 查看智能体的任务

智能体的每项工作都是平台中的一个任务。“运作方式”页右上角的**智能体的任务**打开本项目的任务列表。页面上凡是显示“撰写中”“审核中”“剪辑中”的地方，旁边都有指向对应任务的链接，可以查看进度，也可以在任务中留言补充要求。

智能体对任务的提问也出现在任务中。提问未得到回答时，任务不会继续。

## 练习

1. 在演示项目中查看“等你处理”，记录列出的事项和数量。
2. 依次打开每个页签，对照上表确认其内容。
3. 把页面语言切换为英文再切换回中文，观察页签名称的变化。

## 本章要点

- “等你处理”是每天工作的起点。
- 页签名称旁的数字表示待处理的数量。
- 智能体的工作以任务形式呈现，可以查看和留言。
