# Liteimport 跨境代采

**文档编写中。**

Liteimport 面向从中国进货、发往东南亚的客户：可以直接在 1688 上代采下单，也可以把自己
的包裹预报进来，由我们集运、计费并跟踪到最后一公里。

## 与 TMS 的关系

客户预报的包裹进来后就是 TMS 里的运单——集运、计费和轨迹都走同一套运输流程。TMS 侧的
操作写在 [TMS 用户指南](/guide/tms/)里。

## 1688 商品信息的语言

用泰语浏览时，按关键词或图片搜到的 1688 商品，以及商品详情里的标题、属性和规格，都会翻译成泰语显示。

## 以越南盾（VND）结算

公司的默认货币可以设为越南盾：在后台 **设置 → Company → 公司信息 → 默认货币** 中选择 **VND - Vietnamese Dong**。（Company 这个标签在中文界面里也显示为英文。）

- **PromptPay 二维码按泰铢扣款。** PromptPay 只能以泰铢结算，所以越南盾订单在生成二维码时按当时的汇率换算成泰铢，并向上取整到整铢，确保不会少收。付款页会同时显示订单金额和实际扣款金额，例如“二维码实际扣款 ฿X”；在聊天里收到的付款二维码也同时列出两个金额。订单和付款记录仍以越南盾记账。
- **退款按原汇率退回泰铢。** 用二维码付款的订单退款时，按付款当时的汇率退回泰铢，而不是按退款当天的汇率。部分退款也一样。
- **银行转账不换算。** 以银行转账付款的越南盾订单按越南盾付款，请确认已为公司配置可用的越南盾收款账户。

### 对账：银行流水里的金额

在后台 **Reconciliation**（中文界面里也显示为英文）中导入银行流水时，如果金额里只用了一种分隔符（只有点或只有逗号），按以下规则识别：分隔符出现多次（`1.500.000`、`1,500,000`），或者只出现一次且后面正好跟着三位数字（`500.000`、`1,500`），视为千位分隔符；否则视为小数点（`1500.50`、`1500,5`）。因此 `500.000` 越南盾读作 50 万，`1,500` 泰铢读作 1500。点和逗号同时出现时（`1,234.56`、`1.234,56`），仍以最后一个分隔符为小数点。

## 后台里的 1688 订单号

一个订单向几个 1688 卖家采购时，会有几个 1688 订单号。

- **订单详情页**：在后台 **订单** 中打开订单，**物流追踪** 里的 **1688 订单号** 为每个 1688 订单号单独显示一个链接，点击即在 1688 打开对应的订单。
- **按 1688 订单号搜索**：在 **订单** 列表的搜索框里输入 1688 订单号的开头几位，就能找到订单号中任意一个以此开头的订单。
- **平台管理员的 All orders**：搜索框可以按我们的订单编号或 1688 订单号（同样匹配开头几位）查找订单。（All orders 在中文界面里也显示为英文。）

**也能按淘宝采购单号搜索**：**订单** 列表和 All orders 的搜索框同样能按淘宝采购单号的开头几位找到订单。输入的必须是单号的开头，单号中间的几位找不到订单。输入的位数很少、以此开头的单号很多时，按单号最多找到最新的 100 个订单，多输入几位即可缩小范围。

客户在商城的订单详情里也会看到订单的全部 1688 订单号，以逗号分隔。

**每个 1688 订单号的状态**：订单有几个 1688 订单号时，订单详情页在每个订单号后面的括号里显示 1688 对这笔采购报告的状态，例如 `waitsellersend`（等待卖家发货），按 1688 返回的原样显示。每笔采购的状态各自更新：一个卖家发货了，只有它的订单号状态会变，其他订单号保持原状态。只有一个 1688 订单号的订单不显示这个括号，它的状态显示在 **1688 状态** 一栏里；有几个 1688 订单号的订单不显示 **1688 状态** 一栏。
