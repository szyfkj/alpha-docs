# Liteimport 跨境代采

**文档编写中。**

Liteimport 面向从中国进货、发往东南亚的客户：可以直接在 1688 上代采下单，也可以把自己
的包裹预报进来，由我们集运、计费并跟踪到最后一公里。

## 与 TMS 的关系

客户预报的包裹进来后就是 TMS 里的运单——集运、计费和轨迹都走同一套运输流程。TMS 侧的
操作写在 [TMS 用户指南](/guide/tms/)里。

## 现在能看什么

- 需要接口对接的，看 [开发者指南](/tms/)。
- [自定义域名](./custom-domains.md)：给商城、配送应用和小程序换上自己的域名。
- [分销分析](./affiliate-analytics.md)：分销商带来的推荐、订单和佣金。
- 其他 Liteimport 操作说明，请先联系我们——这份文档正在补。
