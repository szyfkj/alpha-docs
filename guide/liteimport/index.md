# Liteimport 跨境代采

**文档编写中。**

Liteimport 面向从中国进货、发往东南亚的客户：可以直接在 1688 上代采下单，也可以把自己
的包裹预报进来，由我们集运、计费并跟踪到最后一公里。

## 与 TMS 的关系

客户预报的包裹进来后就是 TMS 里的运单——集运、计费和轨迹都走同一套运输流程。TMS 侧的
操作写在 [TMS 用户指南](/guide/tms/)里。

## 1688 商品信息的语言

用泰语浏览时，按关键词或图片搜到的 1688 商品，以及商品详情里的标题、属性和规格，都会翻译成泰语显示。

<Staging source="liteimport#75">

泰语的商品信息改由 1688 直接提供。1688 还没有翻译成泰语的商品会显示中文原文；需要时可以切换到英文查看。之前看过的商品详情可能还会显示原来的译文一段时间。

</Staging>
