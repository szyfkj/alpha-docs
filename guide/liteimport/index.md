# Liteimport 跨境代采

## 以越南盾（VND）结算

公司的默认货币可以设为越南盾：在后台 **设置 → Company → 公司信息 → 默认货币** 中选择 **VND - Vietnamese Dong**。（Company 这个标签在中文界面里也显示为英文。）

- **PromptPay 二维码按泰铢扣款。** PromptPay 只能以泰铢结算，所以越南盾订单在生成二维码时按当时的汇率换算成泰铢，并向上取整到整铢，确保不会少收。付款页会同时显示订单金额和实际扣款金额，例如“二维码实际扣款 ฿X”；在聊天里收到的付款二维码也同时列出两个金额。订单和付款记录仍以越南盾记账。
- **退款按原汇率退回泰铢。** 用二维码付款的订单退款时，按付款当时的汇率退回泰铢，而不是按退款当天的汇率。部分退款也一样。
- **银行转账不换算。** 以银行转账付款的越南盾订单按越南盾付款，请确认已为公司配置可用的越南盾收款账户。

### 对账：银行流水里的金额

在后台 **Reconciliation**（中文界面里也显示为英文）中导入银行流水时，如果金额里只用了一种分隔符（只有点或只有逗号），按以下规则识别：分隔符出现多次（`1.500.000`、`1,500,000`），或者只出现一次且后面正好跟着三位数字（`500.000`、`1,500`），视为千位分隔符；否则视为小数点（`1500.50`、`1500,5`）。因此 `500.000` 越南盾读作 50 万，`1,500` 泰铢读作 1500。点和逗号同时出现时（`1,234.56`、`1.234,56`），仍以最后一个分隔符为小数点。
