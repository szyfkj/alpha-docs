# 淘宝商品

除了 1688，客户在商城里还能搜索、查看并购买淘宝商品。

## 搜索

在商城（网页版、Telegram 小程序、Zalo 小程序）里按关键词搜索时，1688 和淘宝的结果显示在同一个列表里，交替排列。每张商品卡片上都有 **1688** 或 **淘宝** 标签，标明商品来自哪个渠道。没有按渠道筛选的选项。

- **价格**：淘宝商品的价格和 1688 一样，从人民币换算成商城显示的货币，并加上公司设置的加价。
- **排序和价格筛选**：选了排序或价格区间时，对两个渠道的结果一起生效，排好序的列表里 1688 和淘宝商品混在一起。
- **淘宝暂时不可用时**（例如当天的查询次数已用完），搜索只显示 1688 的结果，客户不会看到报错。淘宝响应慢时，搜索最多等淘宝 6 秒，之后先只显示 1688 的结果，不会让客户一直等待。
- **语言**：淘宝商品信息原生提供中文、英文和俄文。其他语言先取英文，再翻译成客户使用的语言，和 1688 商品的处理方式相同。

## 商品详情

点开淘宝商品，会看到图片、标题、价格区间、商品属性和全部规格（选项、价格、库存），页面和 1688 商品一样。底部有 **加入购物车** 和 **立即下单**，选好规格后即可购买。

## 下单

客户在商城（网页版、Telegram 小程序、Zalo 小程序）里下单淘宝商品的方式和 1688 商品相同：选规格、加入购物车、结账。

- **购物车**：同一个购物车里可以同时放 1688 和淘宝商品，每一行都标有 **1688** 或 **淘宝** 标签。只有淘宝商品的购物车也能直接下单。
- **结账**：一次结账里的淘宝商品放进同一个订单。
- **采购**：下单后，订单里的淘宝商品会作为一张淘宝采购单向淘宝下单，收货地址是公司的中国仓库，和 1688 采购相同。在淘宝下单失败不会影响客户的订单，员工可以在后台重新创建（见下方 [在后台处理淘宝采购](#在后台处理淘宝采购)）。
- **付款**：淘宝采购单不会自动付款，由平台按单笔和每日限额统一付款。付款前采购单显示为 **待付款**。平台只为客户已付款、而且没有取消或退款的订单在淘宝付款。

<Staging source="liteimport#127">

**自动付款**：客户付款完成后，平台会自动为这个订单的淘宝采购单付款，不需要等人工操作。客户付款后才创建的采购单（例如 **重新在淘宝创建** 或 **Buy again on Taobao**）创建后马上付款。自动付款同样受单笔和每日限额约束：超过单笔限额、或当天累计会超过每日限额的采购单不会自动付款，仍显示 **待付款**，由平台处理。未取消、未退款的订单才会付款。平台关闭自动付款时，仍由平台逐笔付款。

</Staging>

**1688 和淘宝混合的购物车**：结账后，淘宝商品单独成为一个订单，排在这次结账的最后，就像每个 1688 卖家的商品各成一个订单一样。客户在 **我的订单** 里会看到这些订单，但只需付款一次。

- **总价不变**：客户付的总额和结账页显示的一样。服务费有每单最低收费，但第一个 1688 订单和淘宝订单合起来只收一次服务费，按商品金额分摊到两个订单上，不会因为多一个订单而多收一次最低服务费。
- **运费和优惠券**：运费算在 1688 订单上；优惠券分摊到这次结账的所有订单。
- **各自处理**：1688 订单的取消、退款或完成不影响淘宝商品。淘宝订单的状态跟着淘宝采购单变化，也可以单独退货退款或在淘宝再次购买。

较早下的订单可能同时包含 1688 和淘宝商品。这样的订单状态不跟淘宝采购单变化，和只有 1688 商品的订单一样由 1688 采购决定，避免 1688 商品还没采购订单就显示已发货或已完成。

## 订单状态和物流

在 **我的订单** 列表里，每张订单卡片的订单号旁边都有 **1688** 或 **淘宝** 标签，标明订单是在哪个渠道买的，和商品卡片、订单页上的标签一样。同时有 1688 和淘宝商品的订单会显示两个标签。网页版、Telegram 小程序和 Zalo 小程序都一样。

客户在 **我的订单** 里打开订单，会看到 **淘宝采购** 一栏，显示采购进度：

| 状态 | 含义 |
|---|---|
| 下单中 | 正在向淘宝下单，或等待付款 |
| 已采购 | 已在淘宝付款 |
| 已发往仓库 | 卖家已发货，正在送往中国仓库 |
| 已到达仓库 | 货物已签收 |
| 已关闭 | 采购单在淘宝关闭，会显示关闭原因 |

卖家发货后，这一栏还会显示 **快递单号** 和物流轨迹，轨迹里的电话号码会隐藏。采购状态和物流大约每两小时从淘宝同步一次。

只有淘宝商品的订单，订单状态跟着淘宝采购单变化：付款后变为 **处理中**，发货后变为 **已发货**，签收后变为 **已完成**。变为 **已发货** 后，订单页也会显示 **点击查看物流详情**。

- **仓库预报和发货通知**：采购状态同步时第一次看到某个快递单号，就会为这个包裹向仓库发送预报，并给客户发送物流更新通知，和 1688 采购相同。每个快递单号只预报一次，预报里只包含这个包裹里的淘宝商品。预报或通知失败时，下一次同步会自动重试。
- **取消订单**：淘宝采购单已付款或正在付款时，客户不能取消订单，会看到提示：This order has already been bought, so it cannot be cancelled here. It can still be returned for a refund before it leaves our warehouse: please contact us.（目前只有英文。）付款期间员工取消订单也会失败，稍后再试即可。取消订单不会关闭淘宝上的采购单，但它不会再被付款。
- **退货退款**：已采购的订单，客户可以在订单页自己申请退货退款，见 [退货退款](./returns.md)。

## 在后台处理淘宝采购

在公司后台打开 **订单** 里的某个订单，订单里的淘宝商品带有 **淘宝** 标签，并能打开它在淘宝上的商品页。订单下方的 **淘宝采购单** 卡片显示：

- 状态：**尚未创建**、**创建失败**、**待付款**、**已付款**、**已发货**、**已收货** 或 **已关闭**（附关闭原因）；
- **淘宝采购单号**、**采购金额**、**实付金额** 和付款时间；
- 每个 **子订单** 的运单号和 **物流轨迹**；
- 最近一次失败的原因，以及 **最近检查** 的时间。

<Staging source="liteimport#130">

后台订单页上商品的渠道标签改为在所有界面语言里都显示渠道名称 **TAOBAO**，中文界面里也不再显示 **淘宝**。

</Staging>

**采购金额** 按淘宝采购渠道下单时给出的价格计算，可能和淘宝商品页上的价格略有不同。如果客户选的某个规格无法通过淘宝采购渠道购买，采购单不会创建，卡片显示为 **创建失败**，失败原因会写明这个规格的编号（目前只有英文）。

有订单编辑权限的员工可以在卡片上：

- **重新在淘宝创建**：采购单创建失败或尚未创建时，再试一次。同一个订单不会在淘宝重复下单。创建后仍要等平台付款。已取消或已退款的订单不能重新创建。
- **从淘宝刷新**：立即从淘宝读取最新状态和物流，不用等下一次自动同步。

**待付款** 的采购单会显示 **淘宝采购单由平台管理员付款**，公司员工无法付款。**确认收货** 也只由平台管理员操作：确认后平台付出的货款会打给卖家，也不能再发起争议。货物到仓后由平台确认收货，不需要你操作。

<Staging source="liteimport#127">

客户付款后，采购单通常会自动付款，很快从 **待付款** 变为 **已付款**。客户已付款但采购单一直停在 **待付款**，通常是这笔采购超过了平台的付款限额，正在等平台处理；需要加快时请联系我们。

</Staging>

淘宝账号授权过期或调用失败时，卡片会显示 **淘宝下单已暂停**，此时新的采购单无法创建或更新，请联系我们。

只有淘宝商品的订单不显示 **1688 订单号** 一栏（以及在 1688 下单、同步的按钮），因为没有需要在 1688 处理的内容。

### 采购单关闭后

淘宝会关闭超时未付款的采购单，卖家也可以关闭采购单。**已关闭** 的采购单卡片会说明原因，并提供两个操作（需要订单编辑权限）：

- **Buy again on Taobao**（再次在淘宝购买）：为这个订单里的淘宝商品在淘宝新建一张采购单。新采购单和第一张一样，要等平台付款，也受同样的单笔和每日限额约束。只有客户已付款、订单没有取消或退款时才能使用，而且同一时间一个订单最多只有一张未关闭的采购单。
- **Mark as settled**（标记为已处理）：已经用其他方式处理了这张关闭的采购单时使用，例如通过取消订单或同意退货给客户退了款，或者已经手动购买。这个操作不会购买任何东西，也不会退款，卡片上会显示标记时间。

订单不满足再次购买的条件时（例如订单已取消或已退款），只是没有 **Buy again on Taobao**，卡片改为说明客户付款后、订单没有取消或退款时才能再次购买；**Mark as settled** 仍然可以使用。

再次购买后，订单页按时间倒序显示这个订单的全部淘宝采购单，最新的在最上面，只有最新一张可以操作；旧的显示为已关闭并被上面较新的采购单取代。客户在 **我的订单** 里只看到当前这一张。

这两个按钮和相关提示在中文后台里目前显示英文。

## 粘贴商品链接

在网页版商城的搜索框，或 Telegram、Zalo 小程序首页和搜索页的搜索框里粘贴淘宝或 1688 商品链接，会直接打开这个商品。在聊天里发给客服机器人的商品链接，也会识别为商城里的对应商品。可以识别的淘宝链接包括：

- `item.taobao.com/item.htm?id=…`
- `h5.m.taobao.com/…detail.htm?id=…`
- `m.intl.taobao.com/…?id=…`
- `world.taobao.com/item/<商品编号>.htm`
- 淘宝 App 分享出来的短链接 `m.tb.cn/…` 和 `e.tb.cn/…`

从淘宝 App 复制的分享文字可以整段粘贴，不用单独挑出链接。短链接已失效或指向天猫商品时无法打开商品，会按关键词搜索处理。

## 开通

淘宝渠道默认对所有公司开通，不需要在公司后台设置，但平台可以为单个公司关闭。关闭后，这个公司的商城：

- 搜索结果里不再有淘宝商品，只显示 1688 的结果；
- 打开淘宝商品页（包括粘贴的淘宝链接）会显示商品不存在；
- 购物车里还有淘宝商品时无法结账，需要先把淘宝商品从购物车删除。

已经下的订单不受影响，里面的淘宝采购照常处理。开通或关闭后最多约一分钟生效。商城的搜索结果里没有淘宝商品，或者需要为你的公司关闭或重新开通淘宝时，请联系我们。
