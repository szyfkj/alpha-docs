# 淘宝商品

除了 1688，客户在商城里还能搜到并查看淘宝商品。目前只能搜索和查看详情，淘宝商品还不能下单。

<Staging source="liteimport#101">

现在淘宝商品也可以加入购物车并下单，见下方 [下单](#下单)。

</Staging>

## 搜索

在商城（网页版、Telegram 小程序、Zalo 小程序）里按关键词搜索时，1688 和淘宝的结果显示在同一个列表里，交替排列。每张商品卡片上都有 **1688** 或 **淘宝** 标签，标明商品来自哪个渠道。没有按渠道筛选的选项。

- **价格**：淘宝商品的价格和 1688 一样，从人民币换算成商城显示的货币，并加上公司设置的加价。
- **排序和价格筛选**：选了排序或价格区间时，对两个渠道的结果一起生效，排好序的列表里 1688 和淘宝商品混在一起。
- **淘宝暂时不可用时**（例如当天的查询次数已用完），搜索只显示 1688 的结果，客户不会看到报错。
- **语言**：淘宝商品信息原生提供中文、英文和俄文。其他语言先取英文，再翻译成客户使用的语言，和 1688 商品的处理方式相同。

<Staging source="liteimport#104">

淘宝响应慢时，搜索最多等淘宝 6 秒，之后先只显示 1688 的结果，不会让客户一直等待。

</Staging>

## 商品详情

点开淘宝商品，会看到图片、标题、价格区间、商品属性和全部规格（选项、价格、库存），页面和 1688 商品一样。底部原来的 **加入购物车** 和 **立即下单** 换成了提示 **淘宝下单功能即将上线**。

<Staging source="liteimport#101">

提示 **淘宝下单功能即将上线** 已去掉。淘宝商品页底部和 1688 商品一样，有 **加入购物车** 和 **立即下单**，选好规格后即可购买。

</Staging>

<Staging source="liteimport#101">

## 下单

客户在商城（网页版、Telegram 小程序、Zalo 小程序）里下单淘宝商品的方式和 1688 商品相同：选规格、加入购物车、结账。

- **购物车**：同一个购物车里可以同时放 1688 和淘宝商品，每一行都标有 **1688** 或 **淘宝** 标签。只有淘宝商品的购物车也能直接下单。
- **结账**：一次结账里的淘宝商品放进同一个订单。购物车里有一个 1688 卖家的商品加上淘宝商品时，结账后仍然只有一个订单。
- **采购**：下单后，订单里的淘宝商品会作为一张淘宝采购单向淘宝下单，收货地址是公司的中国仓库，和 1688 采购相同。在淘宝下单失败不会影响客户的订单，员工可以在后台重新创建（见下方 [在后台处理淘宝采购](#在后台处理淘宝采购)）。
- **付款**：淘宝采购单不会自动付款，由平台按单笔和每日限额统一付款。付款前采购单显示为 **待付款**。

## 订单状态和物流

客户在 **我的订单** 里打开订单，会看到 **淘宝采购** 一栏，显示采购进度：

| 状态 | 含义 |
|---|---|
| 下单中 | 正在向淘宝下单，或等待付款 |
| 已采购 | 已在淘宝付款 |
| 已发往仓库 | 卖家已发货，正在送往中国仓库 |
| 已到达仓库 | 货物已签收 |
| 已关闭 | 采购单在淘宝关闭，会显示关闭原因 |

卖家发货后，这一栏还会显示 **快递单号** 和物流轨迹，轨迹里的电话号码会隐藏。采购状态和物流大约每两小时从淘宝同步一次。

只有淘宝商品的订单，订单状态跟着淘宝采购单变化：付款后变为 **处理中**，发货后变为 **已发货**，签收后变为 **已完成**。

<Staging source="liteimport#104">

- **仓库预报和发货通知**：采购状态同步时第一次看到某个快递单号，就会为这个包裹向仓库发送预报，并给客户发送物流更新通知，和 1688 采购相同。每个快递单号只预报一次，预报里只包含这个包裹里的淘宝商品。预报或通知失败时，下一次同步会自动重试。
- **查看物流**：只有淘宝商品的订单变为 **已发货** 后，订单页也会显示 **点击查看物流详情**。
- **1688 和淘宝混合的订单**：订单状态不跟淘宝采购单变化，和只有 1688 商品的订单一样，由 1688 采购决定，避免 1688 商品还没采购订单就显示已发货或已完成。
- **付款前提**：平台只为客户已付款、而且没有取消或退款的订单在淘宝付款。取消订单不会关闭淘宝上的采购单，但它不会再被付款。
- **取消订单**：淘宝采购单已付款或正在付款时，客户不能取消订单，会看到提示：This order has already been bought, so it cannot be cancelled here. It can still be returned for a refund before it leaves our warehouse: please contact us.（目前只有英文。）付款期间员工取消订单也会失败，稍后再试即可。

</Staging>

<Staging source="liteimport#107">

客户现在可以在订单页自己申请退货退款，不必联系我们，见 [退货退款](./returns.md)。

</Staging>

## 在后台处理淘宝采购

在公司后台打开 **订单** 里的某个订单，订单里的淘宝商品带有 **淘宝** 标签，并能打开它在淘宝上的商品页。订单下方的 **淘宝采购单** 卡片显示：

- 状态：**尚未创建**、**创建失败**、**待付款**、**已付款**、**已发货**、**已收货** 或 **已关闭**（附关闭原因）；
- **淘宝采购单号**、**采购金额**、**实付金额** 和付款时间；
- 每个 **子订单** 的运单号和 **物流轨迹**；
- 最近一次失败的原因，以及 **最近检查** 的时间。

有订单编辑权限的员工可以在卡片上：

- **重新在淘宝创建**：采购单创建失败或尚未创建时，再试一次。同一个订单不会在淘宝重复下单。创建后仍要等平台付款。
- **从淘宝刷新**：立即从淘宝读取最新状态和物流，不用等下一次自动同步。
- **确认收货**：子订单到仓后，可以在淘宝确认收货。确认后货款会打给卖家，请在货物确实到仓后再操作。

**待付款** 的采购单会显示 **淘宝采购单由平台管理员付款**，公司员工无法付款。淘宝账号授权过期或调用失败时，卡片会显示 **淘宝下单已暂停**，此时新的采购单无法创建或更新，请联系我们。

</Staging>

<Staging source="liteimport#104">

只有淘宝商品的订单不再显示 **1688 订单号** 一栏（以及在 1688 下单、同步的按钮），因为没有需要在 1688 处理的内容。已取消或已退款的订单不能 **重新在淘宝创建**。

</Staging>

<Staging source="liteimport#109">

### 采购单关闭后

淘宝会关闭超时未付款的采购单，卖家也可以关闭采购单。以前关闭的采购单无法再处理，现在 **已关闭** 的采购单卡片会说明原因，并提供两个操作（需要订单编辑权限）：

- **Buy again on Taobao**（再次在淘宝购买）：为这个订单里的淘宝商品在淘宝新建一张采购单。新采购单和第一张一样，要等平台付款，也受同样的单笔和每日限额约束。只有客户已付款、订单没有取消或退款时才能使用，而且同一时间一个订单最多只有一张未关闭的采购单。
- **Mark as settled**（标记为已处理）：已经用其他方式处理了这张关闭的采购单时使用，例如通过取消订单或同意退货给客户退了款，或者已经手动购买。这个操作不会购买任何东西，也不会退款，卡片上会显示标记时间。

订单不满足再次购买的条件时，卡片只说明采购单已关闭，以及客户付款后、订单没有取消或退款时才能再次购买。

再次购买后，订单页按时间倒序显示这个订单的全部淘宝采购单，最新的在最上面，只有最新一张可以操作；旧的显示为已关闭并被上面较新的采购单取代。客户在 **我的订单** 里只看到当前这一张。

这两个按钮和相关提示在中文后台里目前显示英文。

</Staging>

## 粘贴淘宝链接

在网页版商城的搜索框，或 Telegram、Zalo 小程序的搜索页里粘贴淘宝商品链接，会直接打开这个商品。可以识别的链接包括：

- `item.taobao.com/item.htm?id=…`
- `h5.m.taobao.com/…detail.htm?id=…`
- `m.intl.taobao.com/…?id=…`
- `world.taobao.com/item/<商品编号>.htm`

`m.tb.cn` 开头的短链接还不能直接打开，会按关键词搜索处理。可以先在浏览器里打开短链接，再复制跳转后的完整链接。

<Staging source="liteimport#104">

Telegram 和 Zalo 小程序首页的搜索框现在也能识别粘贴的 1688 或淘宝商品链接，直接打开商品，和网页版一样；以前会把链接当作关键词搜索。在聊天里发给客服机器人的淘宝链接，也会识别为商城里的对应商品。

</Staging>

## 开通

淘宝渠道由平台统一开通，所有商城共用，不需要在公司后台设置。商城的搜索结果里没有淘宝商品时，请联系我们。
