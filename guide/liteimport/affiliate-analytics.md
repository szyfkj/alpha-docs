# 分销分析

**增长 → 分销分析** 按天显示分销商带来的推荐、订单和佣金，看分销效果随时间怎么变化。能看 **分销联盟** 的账号都能打开它。

只能看分销联盟、看不了订单和客户的账号（例如合作的代理机构）登录后，首页就是分销分析。这些账号只看到自己名下推荐码的数据，而且只有数量和金额汇总，看不到具体客户。

## 筛选

页面右上角有三个下拉框：

- **全部分销商**：只看某一个分销商。
- **全部推荐码**：只看某一个推荐码；选了分销商后，这里只列出它的推荐码。
- **时间段**：最近7天、最近30天（默认）、最近90天、最近12个月。

## 指标

每个指标都和上一个同样长度的时间段比较，显示涨跌。

| 指标 | 含义 |
|---|---|
| 新推荐 | 这段时间内通过推荐码新来的客户 |
| 已转化推荐 | 被推荐的客户在这段时间内付了第一笔订单 |
| 已付款订单 | 被推荐客户在这段时间内付款的订单数 |
| GMV | 这些已付款订单的金额 |
| 下单客户 | 这段时间内有已付款订单的被推荐客户数，同一客户只算一次 |
| 待审核佣金、已审核佣金、已支付佣金 | 这段时间内产生的佣金，按它现在的状态分开 |

## 图表

- **推荐与转化**：每天的新推荐和已转化推荐。
- **已付款订单 GMV**：每天的 GMV。
- **佣金**：每天产生的佣金，按待审核、已审核、已支付叠在一起。

## 导出 CSV

筛选框旁边的 **导出** 按钮会把页面当前显示的数据下载成 CSV 文件，按当前选的分销商、推荐码和时间段导出。数据加载中或加载失败时，按钮不能点。

- 每天一行，和图表用的日期相同。
- 列依次是：日期、新推荐、已转化推荐、已付款订单、GMV、下单客户、待审核佣金、已审核佣金、已支付佣金。金额列的表头带币种，例如 `GMV (THB)`。
- 表头用控制台当前的语言。文件是带 BOM 的 UTF-8，用 Excel 打开时中文、泰文、越南文名称也能正常显示。
- 文件名是 `affiliate-analytics_<开始日期>_<结束日期>.csv`；选了推荐码时，推荐码会加在中间，例如 `affiliate-analytics_AGA10_2026-10-08_2026-11-07.csv`。
- 文件里没有合计行：同一个客户在不同日子下单会在每一天各算一次，把“下单客户”逐日相加会多算。合计请看页面上方的指标。
