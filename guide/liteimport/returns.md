# 退货退款

订单已经采购（在 1688 或淘宝下单付款）之后，就不能再取消了，但客户可以申请退货退款：整个订单退回卖家，按客户实付的金额退款，扣除退货运费。所有购物渠道（1688、淘宝）和所有商城（网页版、Telegram 小程序、Zalo 小程序）都一样。

还没采购的订单仍然用 **取消订单**，全额退款，不需要审核。

## 规则

- **整单退货**：只能退整个订单，不能只退其中的包裹或商品。
- **包裹离开中国仓库之前**：只要订单的包裹还在我们的中国仓库（还没随集运发出），就可以退。有一个包裹已经发出，整单都不能退。
- **退款金额 = 客户实付金额 − 退货运费**。退货运费由员工在批准时填写，可以是 0。
- **批准后立即退款**：退款直接转入客户在商城登记的银行账户。

## 客户：申请退货

已付款、已采购的订单，在订单页会看到 **退货退款** 一栏：

> 包裹离开我们的仓库之前，您可以申请退货退款。如退回卖家产生运费，将从退款中扣除。

1. 点 **退货退款**，在弹出的窗口里填写退货原因（不填原因不能提交）。
2. 点 **提交退货申请**。

之后这一栏显示申请的进度：

| 状态 | 客户看到 |
|---|---|
| **已申请退货** | 我们正在审核您的申请。 |
| **退货已批准** | 退货运费和退款金额，以及“退款 … 正在转入您的银行账户。” |
| **已退货退款** | “… 已退回您的银行账户。” |
| **退货申请未通过** | 员工填写的备注（如有）。 |

退款还没到账时，这一栏会提供 **核对您的银行账户信息** 的链接，方便客户检查或补填银行账户。

## 员工：审核申请

客户的申请显示在后台订单详情页的 **退款申请** 一栏，标为 **退回卖家**，并附上客户填写的原因。有订单编辑权限的员工可以处理。

1. 在 **退货运费（…），从退款中扣除** 中填写把包裹退回卖家的运费。下面会显示“将向客户退款 …”。
2. 点 **批准并退款**，或者填写备注后点 **拒绝**。拒绝时，备注会显示给客户。

点 **批准并退款** 后：

- 系统通知仓库把该订单的所有包裹退回卖家，**退回的包裹** 一行列出这些包裹的单号。
- 订单标记为 **已退款**；扣了退货运费时标记为部分退款。
- 立即通过银行转账向客户退款，并通知客户。

如果有包裹已经离开仓库，批准会失败：已经通知退回的包裹会撤回，不会退款，申请仍然是 **待处理**，员工可以拒绝它。

批准之后才发货的包裹（卖家发货较晚），在仓库收到预报时也会自动安排退回卖家。

### 退款没能自动支付

退款无法自动转账时（例如 **客户尚未登记银行账户。** 或 **支付网关不支持客户的银行。**），退货仍然有效，**退款支付** 显示 **失败**。员工可以：

- 等客户补好银行账户后点 **重试支付**；或者
- 用其他方式转账后，在 **已通过其他方式支付：转账参考号** 中填写转账参考号，点 **记录为已支付**。

支付网关没有给出明确结果时，**退款支付** 显示 **结果未知**，页面上给出这笔退款的交易号。请先到支付网关按交易号查询，再点 **已支付** 或 **未支付**；在此之前不能用其他方式再付一次，以免重复退款。

批准或退款支付中途没有完成时，页面会提示，并提供 **继续批准** 或 **重试支付**。继续批准时沿用已经填写的退货运费。

## 退货不包括

- 退还客户使用的积分或优惠券。
- 向 1688 或淘宝卖家申请退款：这一步由员工在 1688 或淘宝上自行处理。
