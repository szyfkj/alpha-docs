# 用户指南

这里写给**使用** Alpha Cargo 的人：录单的操作员、排车的调度、对账的财务、扫码的司机，
以及查件的收件人。

如果你要把自己的系统接进来、调接口，请看[开发者指南](/tms/)。

## 选择产品

| 产品 | 做什么 | 状态 |
|---|---|---|
| [TMS 运输管理](/guide/tms/) | 运单、配送排车、司机扫码、计费对账 | 可用 |
| [WMS 仓储管理](/guide/wms/) | 入库、库存、拣货、出库 | 文档编写中 |
| [Voice 语音](/guide/voice/) | 语音交互与通话处理 | 文档编写中 |
| [Liteimport 跨境代采](/guide/liteimport/) | 1688 代采、包裹预报、集运到东南亚 | 文档编写中 |
| [Video 短视频](/guide/video/) | 短视频下载、转写翻译、剪辑与投放数据 | 文档编写中 |

## 怎么读

不必从头读到尾。按你的角色挑：

- **第一次用** —— 先读 TMS 的[开始使用](/guide/tms/)，把几个核心概念对上号，再回来查具体功能。
- **日常操作** —— 直接找对应的功能页，每页都是从菜单入口开始的分步操作。
- **司机** —— 只需要看司机那一章。

文档里写到的菜单和按钮，用的都是产品界面上的原词。界面支持中文和英文，本文档也是——
右上角可以切换。
